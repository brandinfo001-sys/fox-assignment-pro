How to view:
1. Extract the ZIP.
2. Double-click index.html.
3. The website opens in your browser.
4. To edit text, open the HTML files in a code editor such as Visual Studio Code.
5. To change colours/design, edit css/style.css.

The contact form opens WhatsApp rather than storing submissions on a server.
